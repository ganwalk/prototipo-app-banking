# AUVP × BTG Pactual — Protótipo Mobile

Protótipo de app bancário mobile (React + TypeScript + Vite + Tailwind CSS v4), construído a partir do [design system AUVP](https://produtosauvp.github.io/central/design-system).

## Telas

- **Login** — boas-vindas personalizadas, branding AUVP + BTG Pactual.
- **Home** — carrossel de contas (conta corrente, cartão, investimentos, empréstimos, seguros), atalhos, banners promocionais e atividades recentes.
- **Menu** — visão consolidada de produtos em faixas coloridas.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:5173`. A visualização é otimizada para viewport mobile (o layout ganha uma moldura de device em telas largas).
